# インバウンドマップ

国籍別の延べ宿泊者数・国際線・客室稼働率を見る地図サイトです。GitHub Pages では `index.html` を配信しています。

## ニュースまとめの更新

「ニュースまとめ」の本文は `news.json` です。地図本体の `index.html`（約 3MB）は日次更新では触りません。マスターの Excel から JSON だけ作り直し、そのファイルをコミットしてください。

Excel（`旅行業界ニュース` と `海外OTAニュース` の2シート）が、載せる項目と文言の正です。Google スプレッドシートの CSV は、出典・ソース列の URL を全部取り込むために使います（Excel のセルにはハイパーリンクが1つしか入りません）。日付と見出しが一致した行だけ CSV の URL を使い、一致しない場合は Excel のハイパーリンクに戻します。

各項目には元のカテゴリに加えて `theme` が入ります。画面の絞り込みチップは「すべて」「新規開業ホテル」「新規フライト情報」の順です。海外OTA（Expedia・Hotelbeds・サイトコントローラーなどの卸・配信も含む）と国内OTA・旅行会社の項目はチップを出さず、「すべて」に残します。国際線フライト（`theme` が `flights`）は「新規フライト情報」にだけ出し、「すべて」には月や他の絞り込みと組み合わせても出しません。チップの件数もそれに合わせます。国際線のテーマ名は「新規フライト情報」です。シートのカテゴリ「国際線」は東京以外の路線（関西・長崎など）も含めてこのテーマにします。行政・インバウンド施策とその他に振り分けた項目は、チップからも「すべて」からも外します。振り分け規則は `scripts/build_news.py` の `assign_theme` にあり、見出しの先頭の話題を優先します。📌要点はチップにせず、その日の要約として日付の先頭に出ます。

絞り込みには、チップとは別に「他旅行会社動向」と月の選択があります。他旅行会社動向は海外OTA・国内OTAに、見出しが大手旅行会社・ランドオペレーター・卸/B2Bの項目を足します。各項目の `companies` はその結果です。無い古い `news.json` でも画面が同じ規則で判定します。月を選ぶと、その月の該当記事を日付・テーマ・見出しの箇条書きにします。月の候補は `news.json` にある月から作るので、日次更新で新しい月が増えてもそのまま使えます。

新規フライト情報の各項目には `flightTags`（新規・増便・再開・減便・運休・変更）が入ります。見出しと本文から `flight_tags` が付け、画面は見出しの上と月別の箇条書きに色分けして出します。フィールドが無い古い `news.json` でも、画面が見出しから同じ種類を補います。

必要なもの: Python 3 と [openpyxl](https://openpyxl.readthedocs.io/)（`pip install -r scripts/requirements.txt`）。

```bash
python3 scripts/build_news.py /path/to/旅行業界・海外OTAニュース.xlsx \
  --industry-csv /path/to/gsheet_industry.csv \
  --ota-csv /path/to/gsheet_ota.csv \
  -o news.json
```

CSV が無い日は `--industry-csv` と `--ota-csv` を省けます。日付に年が無い行は `--year`（既定 2026）を使い、新しい順に読んで月が戻ったら前年とみなします。

```bash
python3 scripts/build_news.py /path/to/旅行業界・海外OTAニュース.xlsx -o news.json
```

生成した `news.json` をリポジトリ直下に置いて push すると、サイトの「ニュースまとめ」ボタンが次回表示時にその内容を読み込みます。

「新規開業ホテル」を選ぶと、ニュースの上に `hotel_openings.json` の全国リスト（2026年10月以降）を出します。このファイルはチップを開いたときだけ読みます。最終更新日は JSON の `updated` です。`発表日` があるホテルだけ、開業日の横にその日付を出します。無いホテルは空欄です。並びの既定は開業日順のままです。
